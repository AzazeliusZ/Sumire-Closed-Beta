# Сумирэ — My Little AI Companion 0.6.9

Предварительная Windows x64 сборка **Easy Setup & Community Feedback**. Сумирэ может общаться через облачную или локальную модель. Облачного текстового чата достаточно для первого знакомства; озвучивание, микрофон и анализ изображения настраиваются отдельно.

- [Что проверить](TESTERS-RU.md) · [Заметки о версии](RELEASE-NOTES-RU.md)

Официальные выпуски: [GitHub](https://github.com/AzazeliusZ/Sumire-Closed-Beta). Контакт: **Sumire Developer** — [sumirehelp@gmail.com](mailto:sumirehelp@gmail.com).

В ZIP есть приложение и его .NET Runtime. Ollama, LM Studio, Python-окружения и веса моделей в пакет не входят. Функции, которым они не нужны, можно использовать без их установки. Не отключайте Defender, SmartScreen или другие механизмы Windows.
