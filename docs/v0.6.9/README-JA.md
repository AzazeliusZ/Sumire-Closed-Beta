# すみれ — My Little AI Companion 0.6.9

**Easy Setup & Community Feedback** は Windows x64 向けのプレビュー版です。クラウドまたはローカルの AI で会話できます。まずはテキストで会話し、読み上げ、マイク、画像解析は必要になったときに設定できます。

- [はじめに](START-HERE-JA.md)・[動作環境](SYSTEM-REQUIREMENTS-JA.md)・[導入手順](INSTALL-JA.md)
- [テスター向けのご案内](TESTERS-JA.md)・[リリースノート](RELEASE-NOTES-JA.md)

公式配布先：[GitHub](https://github.com/AzazeliusZ/Sumire-Closed-Beta)。お問い合わせ：**Sumire Developer** — [sumirehelp@gmail.com](mailto:sumirehelp@gmail.com)。

ZIP にはアプリと .NET ランタイムが含まれています。Ollama、LM Studio、Python 環境、モデルデータは同梱されていません。使う機能に必要なものだけを導入してください。Microsoft Defender や SmartScreen など、Windows の保護機能は有効なままにしてください。
