# Installation and recovery

- **Ollama.** Select Local AI → Install Ollama in setup. The first confirmation allows a metadata request; the second starts the installer download. Sumire checks the published GitHub SHA-256 and the Windows signature. Complete or cancel the install in Ollama’s own window. If its server has not started, open Ollama from the Start menu and detect it again. You can also use the [official download](https://ollama.com/download/windows).
- **Model.** Select a recommended model or enter a local Ollama tag, then approve its download. Choose “Test and save”. For LM Studio, install the [official app](https://lmstudio.ai/download), start its local server, and find models. Manual setup supports loopback OpenAI-compatible endpoints; it does not send keys to arbitrary hosts.
- **Voice.** Each optional component needs its own approval. If an environment is damaged, open Settings → Diagnostics Center → Repair a component in setup. Reinstalling builds a new environment for only that component and reuses any verified model files. In Voice Studio, save a voice and then listen in Russian, English or Japanese. “Restore Ono_Anna” restores the default.
- **Downloads.** A connection error may leave a partial installer for retry. If the server does not support resuming, setup restarts that download. Cancellation before opening the installer removes its partial file. A separate cleanup action removes leftover installers. Ollama owns its model cache.
- **Updates and resources.** Diagnostics offers manual GitHub release checks, a prerelease channel, and optional reminders. The app does not download or replace its EXE. Unloading a model requires confirmation and a compatible server; it does not stop Ollama or LM Studio.

Upgrade: close the old app, extract 0.6.9 to a **new folder**, and keep 0.6.8.1. The profile stays in `%LOCALAPPDATA%\MyLittleAICompanion-SumireAlpha`. At first start 0.6.9 backs up existing settings to `Before-0.6.9/settings.json`. To roll back, close 0.6.9 and open the old EXE. To restore the exact settings from the upgrade, make a copy of the current settings.json before restoring the backup. Leave DPAPI stores and chat history in place.
