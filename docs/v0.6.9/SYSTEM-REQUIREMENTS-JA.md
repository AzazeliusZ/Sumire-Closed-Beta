# 動作環境

| 用途 | 必要な環境 |
|---|---|
| アプリ・クラウドのテキスト会話 | Windows 10 x64（ビルド 19041 以降）または Windows 11 x64。RAM 8 GiB、ZIP 展開用の空き容量 500 MiB が目安です。クラウドにはネット接続とキーが必要で、専用 GPU は不要です。 |
| セットアップ内の Ollama 導入 | x64 版 Windows 10 22H2 以降。現在のインストーラー容量を案内します。導入用に 4 GiB 以上と、ダウンロード用の空き容量が別途必要です。モデルの容量は含みません。 |
| ローカルのテキスト会話 | 空き RAM、専用 GPU メモリの予算、ディスクの空き容量をもとに推奨します。Qwen3 1.7B は CPU でも使える軽量候補です。共有 GPU メモリは専用 VRAM と区別します。 |
| 音声認識 | マイク、Python 環境、Faster-Whisper。CPU 向けの自動準備には AVX に対応した x64 CPU が必要です。 |
| 読み上げ | セットアップ済みの Qwen3-TTS CustomVoice 0.6B または 1.7B。自動導入は対応する NVIDIA CUDA/BF16 環境向けです。AMD、Intel、CPU のみでの TTS は未確認です。 |
| 画面解析 | 画像入力に対応するローカルモデルの設定と、画面取得に対する明示的な許可が必要です。 |

アプリから GPU ドライバーを導入することはありません。LLM、TTS、VLM を併用する場合は、RAM と VRAM に余裕を持たせてください。[Ollama の公式動作環境](https://docs.ollama.com/windows)もご覧ください。
