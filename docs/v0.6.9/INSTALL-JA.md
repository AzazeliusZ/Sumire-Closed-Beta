# 導入・復旧手順

- **Ollama**：セットアップの「ローカル AI」から「Ollama をインストール」を選びます。最初に公式情報の確認、次にダウンロードを承認します。公開済みの SHA-256 と Windows の署名を確認し、Ollama の通常のインストーラーを開きます。続行やキャンセルはその画面で行ってください。サーバーが応答しない場合は、スタートメニューから Ollama を起動して再検出します。[公式ダウンロード](https://ollama.com/download/windows)からの手動導入も可能です。
- **言語モデル**：推奨候補を選ぶか、ローカル用のタグを入力し、ダウンロードを承認してから「接続をテストして保存」を選びます。LM Studio は[公式サイト](https://lmstudio.ai/download)から導入し、ローカルサーバーを起動してモデルを検出します。手動設定の OpenAI 互換エンドポイントはループバック接続が対象です。任意の外部サーバーへ API キーを送る機能はありません。
- **音声**：追加機能の導入には個別の承認が必要です。環境が壊れた場合は「設定 → 診断センター → セットアップでコンポーネントを修復」を開きます。再導入時は対象のみ新しい環境を作り、検証済みモデルを再利用します。ボイススタジオで声を保存し、日・英・露のサンプルを試聴できます。「Ono_Anna に戻す」で標準の声に戻せます。
- **ダウンロード**：通信が途切れると、再試行に備えてインストーラーの途中データが残る場合があります。配布元が途中再開に対応していなければ、最初から取得します。起動前にキャンセルすれば一時ファイルを削除します。残ったインストーラーの一時データだけを消す操作も用意しています。Ollama のモデルキャッシュは Ollama が管理します。
- **更新とリソース**：診断センターでは GitHub の手動確認、プレリリースの選択、任意の定期通知が利用できます。EXE の自動ダウンロードや置き換えは行いません。ローカルモデルのメモリ解放は、対応するサーバーに確認のうえで依頼します。Ollama や LM Studio のプロセスは終了しません。

更新時は旧アプリを終了し、0.6.9 を**別のフォルダー**に展開します。0.6.8.1 は残してください。プロファイルは `%LOCALAPPDATA%\MyLittleAICompanion-SumireAlpha` に保持され、初回起動時に既存の設定だけが `Before-0.6.9/settings.json` にコピーされます。元に戻す場合は 0.6.9 を終了し、旧 EXE を起動します。移行直前の設定まで戻す必要があるときは、現在の settings.json を別途保存してからバックアップを復元してください。履歴や Windows で保護されたデータはそのままにしてください。
