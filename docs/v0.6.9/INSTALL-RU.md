# Установка и восстановление

- **Ollama.** В мастере выберите «Локальный интеллект → Установить Ollama». Первое подтверждение запрашивает официальные метаданные; второе запускает загрузку. Сумирэ проверяет опубликованный GitHub SHA-256 и подпись Windows. Установка идёт через обычное окно Ollama: в нём можно продолжить или отменить. Если сервер не запустился, откройте Ollama в меню «Пуск» и повторите поиск. При необходимости используйте [официальную страницу](https://ollama.com/download/windows).
- **Модель.** Выберите рекомендованную модель или локальный тег вручную, затем подтверждайте загрузку отдельно. Нажмите «Проверить и сохранить». Для LM Studio установите [официальное приложение](https://lmstudio.ai/download), запустите локальный сервер и нажмите «Найти модели». Ручной режим принимает OpenAI-совместимый адрес на loopback; произвольная передача ключей на сторонний сервер не включена.
- **Голос.** Дополнительные компоненты ставятся со своим подтверждением. Если окружение повреждено: «Настройки → Центр диагностики → Восстановить компонент через мастер». Пересоздаётся только выбранное окружение, уже скачанная исправная модель используется повторно. В голосовой студии выберите и сохраните пресет, затем прослушайте RU / EN / JA. Кнопка «Вернуть Ono_Anna» восстанавливает стандартный голос.
- **Загрузки.** Сетевая ошибка может оставить частичный установщик для повтора. Если сервер не поддерживает продолжение, мастер загрузит заново. Отмена до запуска установщика удаляет временный файл; отдельная кнопка очищает остатки установщика. Кэшем моделей управляет Ollama; Сумирэ не чистит его автоматически.
- **Обновления и ресурсы.** В центре диагностики есть ручная проверка GitHub, канал предварительных релизов и опциональное фоновое уведомление. Программа не скачивает или не заменяет EXE. Выгрузка локальной модели поддерживается только совместимым сервером и требует подтверждения; не завершает процесс сервера.

Обновление: закройте прежнюю Сумирэ, распакуйте 0.6.9 в **новую папку**, оставьте 0.6.8.1. Профиль остаётся в `%LOCALAPPDATA%\MyLittleAICompanion-SumireAlpha`; при первом запуске 0.6.9 существующие настройки копируются в `Before-0.6.9/settings.json`. Для отката закройте 0.6.9 и запустите старый EXE. Если нужно вернуть настройки на момент перехода, сначала сохраните текущий settings.json отдельно, затем восстановите его из этой локальной копии. Не переносите DPAPI-копии и не чистите историю.
