# はじめての会話

1. ZIP をフォルダーにすべて展開し、`Windows/MyLittleAICompanion.exe` を起動します。Windows に警告が出た場合は、実行前に配布元と SHA-256 を確認してください。
2. 表示言語を選びます。「すみれの応答方法を選んでください」で、**クラウド AI**、**ローカル AI**、**手動設定**から選びます。
3. クラウドを使う場合は、サービスとモデルを選び、API キーを入力して接続テストを承認します。Yandex AI Studio ではフォルダー ID も必要です。テストには料金が発生する場合があります。「接続をテストして保存」で成功した場合、入力したキーは Windows の保護機能で保存されます。履歴と記憶の利用許可は別々です。
4. ローカルではモデルの検出を実行します。Ollama が必要な場合はバージョンと容量を確認してから導入し、モデルのダウンロードは個別に承認します。最後に「接続をテストして保存」を選びます。詳しくは[導入手順](INSTALL-JA.md)をご覧ください。
5. テキストから始める場合は、音声の設定を飛ばせます。会話の好みも任意です。設定を終えたらチャットを開き、短いメッセージを送ってください。手動設定のオフラインデモでは、外部モデルなしで画面を試せます。

設定済みの環境ではアップデート後にセットアップが自動で開くことはありません。必要に応じて設定画面から開いてください。
