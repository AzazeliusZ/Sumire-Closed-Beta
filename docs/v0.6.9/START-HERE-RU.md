# Первый разговор

1. Полностью распакуйте ZIP в обычную папку. Откройте `Windows/MyLittleAICompanion.exe`. Если Windows не доверяет источнику файла, проверьте источник и SHA-256 перед запуском.
2. Выберите язык. В мастере откройте шаг «Как Сумирэ будет отвечать?». Выберите **Облачный интеллект**, **Локальный интеллект** или **Ручная настройка**.
3. Облачный вариант: выберите провайдера и модель, введите ключ, подтвердите тестовый запрос. Например, Yandex AI Studio также требует идентификатор каталога. Пробный запрос может быть платным. Сумирэ сохраняет введённый ключ защищённым хранилищем Windows после успешного теста и только по кнопке «Проверить и сохранить». Разрешения истории и памяти остаются отдельными.
4. Локальный вариант: нажмите «Найти модели». Для новой установки Ollama сначала покажет версию и размер; модель требует отдельной загрузки. В конце нажмите «Проверить и сохранить». Подробности — в [руководстве](INSTALL-RU.md).
5. Пропустите необязательные голосовые шаги, если начинаете с текста. Укажите пожелания к общению или нажмите «Пропустить». Откройте чат и отправьте короткое сообщение. Офлайн-демо в ручной настройке позволяет открыть чат без внешней модели.

Если Сумирэ уже была настроена, мастер не открывается повторно. Вызвать его можно из настроек.
