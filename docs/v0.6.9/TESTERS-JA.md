# テスター向けのご案内

1. 新しい Windows プロファイルで、ローカルモデルなしのクラウド会話をお試しください。その後、Ollama の導入または LM Studio の検出を確認します。
2. ダウンロード前と途中のキャンセル、通信切断後の再試行を確認してください。インストーラー起動後は、インストーラー側のボタンでキャンセルします。
3. 日・英・露のサンプルを試聴し、Ono_Anna に戻してください。診断センターでメモリ解放と再読み込みを試します。会話中にアプリが勝手に解放しないことも確認してください。
4. 日本語・英語・ロシア語を切り替え、小さいウィンドウと 125～200% の表示スケールで確認します。0.6.8.1 から更新する場合は、履歴、記憶、表示言語が残り、セットアップが再表示されないことも確認してください。
5. 診断レポートをプレビューし、項目を一つ除外してから、保存またはコピーを試します。API キー、会話、個人用のパス、音声や画面画像が含まれないことを確認してください。自動送信はありません。

不具合のご連絡には、アプリと Windows のバージョン、構成、期待した動作と実際の動作、再現手順を添えてください。認証情報は送らないでください。[メール](mailto:sumirehelp@gmail.com)・[GitHub Issues](https://github.com/AzazeliusZ/Sumire-Closed-Beta/issues)
