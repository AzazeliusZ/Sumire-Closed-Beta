# Your first conversation

1. Extract the entire ZIP into a folder. Open `Windows/MyLittleAICompanion.exe`. If Windows raises a trust warning, verify the source and SHA-256 before running it.
2. Choose your language. At “How should Sumire generate replies?” select **Cloud AI**, **Local AI**, or **Manual setup**.
3. For cloud chat, select a provider and model, enter your key, and confirm the test. Yandex AI Studio also needs a folder ID. The test may cost money. A key entered through “Test and save” is stored with Windows protection after a successful test. Chat history and memory permissions stay separate.
4. For local chat, select “Find models”. If you need Ollama, review the installer version and size, then approve it. Model downloads require a separate approval. Finish with “Test and save”. See [Installation](INSTALL-EN.md).
5. You can skip optional voice setup and the communication preferences screen. Open chat and send a short message. The offline demo under Manual setup can show you the interface without an external model.

Updates do not reopen the wizard after setup. You can open it again from Settings.
