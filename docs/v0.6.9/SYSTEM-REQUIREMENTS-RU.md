# Системные требования

| Режим | Что нужно |
|---|---|
| Приложение / облачный текст | Windows 10 x64 (19041+) или Windows 11 x64. Рекомендуется 8 ГиБ RAM и не менее 500 МиБ для распаковки. Для облака — интернет и ключ; дискретная GPU не нужна. Это ориентиры, а не результаты измерения скорости. |
| Настройка Ollama из мастера | x64 Windows 10 22H2 или новее. Мастер показывает текущий размер установщика, резервирует минимум 4 ГиБ для установки плюс файл загрузки. Модели требуют отдельного места. |
| Локальный текст | Мастер оценивает свободные RAM / VRAM / диск. Qwen3 1.7B — лёгкий вариант для CPU. Не считайте разделяемую память встроенной графики выделенной VRAM. |
| Распознавание речи | Микрофон, Python-окружение и Faster-Whisper. Для автоматической подготовки CPU требуется x64 с AVX. |
| Озвучивание | Настроенный Qwen3-TTS CustomVoice 0.6B или 1.7B. Автоматическое развёртывание рассчитано на совместимый NVIDIA CUDA/BF16. Для AMD / Intel и CPU в этой сборке поддержка TTS не подтверждена. |
| Анализ экрана | Отдельно настроенная локальная модель с поддержкой изображений и явное разрешение захвата. |

Драйверы не устанавливаются приложением. При одновременной работе LLM, TTS и VLM оставьте запас RAM и VRAM; планы мастера ориентировочные. См. [официальные требования Ollama](https://docs.ollama.com/windows).
