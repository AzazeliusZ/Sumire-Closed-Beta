# Sumire — My Little AI Companion 0.6.9

**Easy Setup & Community Feedback** is a preview build for Windows x64. Sumire can use a cloud or local model. Start with text chat; voice, microphone, and image analysis can be set up separately.

- [First launch](START-HERE-EN.md) · [System requirements](SYSTEM-REQUIREMENTS-EN.md) · [Installation](INSTALL-EN.md)
- [Tester guide](TESTERS-EN.md) · [Release notes](RELEASE-NOTES-EN.md)

Official releases: [GitHub](https://github.com/AzazeliusZ/Sumire-Closed-Beta). Contact: **Sumire Developer** — [sumirehelp@gmail.com](mailto:sumirehelp@gmail.com).

The archive includes the app and its .NET runtime. It does not contain Ollama, LM Studio, Python environments, or model weights. Install only the components you need. Leave Microsoft Defender, SmartScreen, and other Windows protections enabled.
